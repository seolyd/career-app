# Futures Desk

원유·금·비트코인 세 종목만 보는 선물 트레이딩 앱. 아이폰 PWA 우선.

야후 파이낸스의 화면 문법(스파크라인 썸네일 리스트 → 종목 상세의 탭 네비게이션)을 빌리되,
목적이 다릅니다. 야후는 "내 포트폴리오가 어떻게 됐나"를 보는 앱이고, 이 앱은
**"지금 들어갈 자리인가, 그리고 어제의 나는 어땠나"**를 보는 앱입니다.

| | |
| --- | --- |
| **종목** | 원유 WTI(CL) · 금(GC) · 비트코인(BTC) — 셋 고정, 추가 없음 |
| **홈** | 세 종목 카드. 스파크라인 썸네일 + 시세 + 지표 + 시그널 배지 + 최신 뉴스 한 줄 |
| **상세** | 써머리 · 뉴스 · 시그널 · 저널 4탭 |
| **플랫폼** | React + Vite + TypeScript + Tailwind, PWA(홈화면 설치), Vercel |
| **저장** | 저널·시그널 이력은 IndexedDB(기기 안). 시세·뉴스는 서버리스 프록시 경유 |

## 세 가지 원칙

**1. 시그널은 근거와 함께 나온다.** "매수"만 뜨는 화면은 운세입니다. 어떤 조건이
몇 점을 기여해서 이 방향이 됐는지 항상 펼쳐볼 수 있어야 하고, 납득이 안 되면
그 시그널은 무시할 수 있어야 합니다.

**2. 모든 시그널은 채점된다.** 발생한 시그널은 입력 스냅샷과 함께 저장되고, 이후
가격으로 자동 채점됩니다(T1 도달 / 손절 / 만료). 채점 기록이 없으면 고도화할
근거도 없습니다. 이게 v2의 연료이므로 v1 스키마에 처음부터 들어갑니다.

**3. 언제 거래하지 않을지가 먼저다.** 변동성이 죽었을 때, 세션이 얇을 때, EIA 재고
발표 10분 전일 때는 점수가 몇 점이든 시그널을 내지 않습니다. 필터가 신호보다
가치 있습니다.

## 고지

이 앱은 투자 조언을 하지 않습니다. 시그널은 공개된 가격 데이터에 규칙을 적용한
계산 결과이고, 맞을 거라는 보장이 없습니다. 데이터는 지연되거나 틀릴 수 있으며
실제 주문 판단은 거래하는 증권사 화면과 대조해야 합니다.
