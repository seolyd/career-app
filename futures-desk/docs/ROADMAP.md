# 구축 순서

원칙: **각 단계가 끝날 때마다 실제로 쓸 수 있는 앱**이어야 합니다. 전부 만들어놓고
마지막에 켜보는 방식은 하지 않습니다.

## P0 — 구조 확정 ← 지금 여기

이 문서들. 코드 없음.

## P1 — 골격

레포·툴체인·PWA 셸, `symbols.ts`의 세 종목 정의, `/api/quote` 하나.
홈 화면에 세 카드(현재가 + 변동률 + 스파크라인)가 뜨고, 종목을 누르면 4탭
껍데기가 열립니다. 아이폰 홈화면에 설치됩니다.

> 끝나면: **가격이 보이는 앱**

## P2 — 써머리

`/api/candles`, `lightweight-charts` 캔들 차트, 기간·간격 전환, 핵심 수치 그리드,
지표 순수 함수 전부(EMA·RSI·ATR·MACD·BB·ADX·VWAP·돈치안·OBV) + 단위 테스트,
IndexedDB 캐시와 stale-while-revalidate.

> 끝나면: **차트와 지표를 보는 앱**

## P3 — 저널

작성·수정·삭제·실행취소, 태그, 가격 첨부, 날짜 그룹, 검색, 내보내기.

**저널을 시그널보다 먼저 만듭니다.** 외부 데이터에 전혀 의존하지 않아서 혼자
완결되고, 오프라인에서도 동작하고, 무엇보다 이 시점부터 앱을 매일 열 이유가
생깁니다. 시그널 엔진을 나중에 튜닝할 때 "그때 내가 뭘 봤는지"의 기록도 이때부터
쌓이기 시작합니다.

> 끝나면: **매일 열 이유가 있는 앱**

## P4 — 뉴스

`/api/news` RSS 수집·파싱·중복 제거·종목 라우팅, 뉴스 탭, 필터 칩, 읽음 상태,
예정 이벤트 스트립.

> 끝나면: **왜 움직였는지 알 수 있는 앱**

## P5 — 시그널 v1

게이트 → 레짐 → 디텍터 6 → 합성 → 거래계획. 가중치는 손으로 정한 값.
시그널 카드, 디텍터 막대, 레짐 배지. 알림은 아직 없음.

검증: 지난주 캔들 리플레이로 시그널을 차트에 찍어보고 눈으로 확인.

> 끝나면: **근거가 보이는 시그널이 뜨는 앱**

## P6 — 채점

발생 시그널 저장(스냅샷 포함), 자동 채점, MFE/MAE, 성적표, 디텍터별 성적.
**여기서 처음으로 가중치를 데이터 근거로 고칩니다.**

> 끝나면: **스스로 나아지는 앱**

## P7 — 고도화

- 경제지표 캘린더 API (이벤트 게이트 자동화)
- BTC 펀딩비·미결제약정 디텍터
- 금-DXY 상관 디텍터
- 원유 브렌트 스프레드 디텍터
- 웹푸시 알림 (iOS 16.4+, 설치 상태)
- 백테스트 모드 + 가중치 탐색

## 미루는 것들

| 항목 | 이유 |
| --- | --- |
| 종목 추가 | 셋에 특화된 문맥 디텍터가 이 앱의 이점입니다. 종목을 늘리면 그냥 야후가 됩니다 |
| 계정·동기화 | 기기 하나로 충분하고, 서버에 거래 기록을 올릴 이유가 없습니다 |
| 자동 주문 | 시그널과 집행 사이에 사람이 있어야 합니다 |
| 실시간 호가창 | 무료 데이터로는 불가능하고, 앱의 시간 단위(5분봉)에 필요하지 않습니다 |
| 머신러닝 | 자기 데이터 6개월이 쌓이기 전에는 과적합 장치일 뿐입니다 |
