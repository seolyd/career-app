# 화면 구조

아이폰 세로 화면 기준. 야후 파이낸스의 문법을 빌리되 종목이 셋뿐이라
"검색·워치리스트 관리"에 해당하는 것들은 전부 들어냅니다.

## 네비게이션

```
/                    마켓 (홈)
/s/:symbol           종목 상세 — 기본 써머리
/s/:symbol/news
/s/:symbol/signal
/s/:symbol/journal
/signals             전체 시그널 (3종목 통합)
/journal             전체 저널 (3종목 통합, 날짜순)
/settings
```

하단 탭 4개: **마켓 · 시그널 · 저널 · 설정**

뉴스를 하단 탭에 넣지 않은 건 의도입니다. 종목이 셋뿐이라 통합 뉴스 피드가
종목별 뉴스 탭과 거의 같아집니다. 반면 시그널과 저널은 통합 뷰가 확실히 다른
쓸모가 있습니다 — "지금 세 종목 중 어디에 신호가 켜졌나", "이번 주 내가 뭘 썼나".

종목 상세로 들어가면 하단 탭은 유지하고 상단에 4개 탭이 하나 더 생깁니다.
야후와 같은 구조입니다(전역 탭 + 종목 내 탭).

---

## 홈 — 마켓

```
┌─────────────────────────────────────────┐
│  Futures Desk          09:41  ↻ 방금 전 │   ← 마지막 갱신 시각, 당겨서 새로고침
│  3종목 중 1개 신호 켜짐 · 원유 롱        │   ← 한 줄 요약
├─────────────────────────────────────────┤
│                                         │
│  원유 WTI        CL      ● 정규장       │   ← 세션 상태 점(활성/얇음/휴장)
│  $63.42                    ╱╲   ╱      │   ← 스파크라인(1D)
│  +1.04  (+1.67%)      ╲__╱  ╲_╱        │      전일종가 점선 기준
│  ────────────────────────────────────   │
│  저 62.80 ┤━━━━━●━━━━┤ 고 63.90        │   ← 일중 범위 바, ●가 현재가
│  거래량 428K (평균比 1.4배) · ATR 0.71  │
│  ────────────────────────────────────   │
│  ▲ LONG  72                             │   ← 시그널 배지 (색 + 확신도)
│  "EIA 재고 발표 3시간 뒤" · 12분 전      │   ← 최신 뉴스/이벤트 한 줄
│                                         │
├─────────────────────────────────────────┤
│  금              GC      ● 정규장       │
│  ...                                    │
├─────────────────────────────────────────┤
│  비트코인        BTC     ● 24시간       │
│  ...                                    │
└─────────────────────────────────────────┘
```

**카드 한 장의 구성 (위→아래)**
1. 종목명 · 티커 · 세션 상태 점
2. 현재가(가장 큰 글자) / 변동 절대값·퍼센트 (상승 빨강, 하락 파랑 — 설정에서 반전 가능)
3. 스파크라인 썸네일 — 1D 5분봉, 방향에 따라 색, 전일종가에 점선
4. 일중 범위 바 + 거래량(평균 대비 배수) + ATR
5. 시그널 배지 — `▲ LONG 72` / `▼ SHORT 65` / `— WAIT` (게이트에 걸리면 사유 한 줄)
6. 가장 최근 뉴스 헤드라인 또는 임박한 이벤트 + 경과 시간

**동작**
- 카드 탭 → 종목 상세(써머리)
- 시그널 배지 탭 → 종목 상세의 시그널 탭으로 바로
- 길게 누르기 → 빠른 저널 작성 시트(현재가가 자동 첨부됨)
- 당겨서 새로고침 / 포그라운드일 때 15초 자동 갱신

**스파크라인 기간 토글** — 상단에 1D · 5D · 1M 칩. 세 카드에 동시 적용됩니다.

## 종목 상세

```
┌─────────────────────────────────────────┐
│  ‹  원유 WTI  $63.42  +1.67%            │   ← 스크롤하면 큰 가격이 접혀서
├─────────────────────────────────────────┤      이 한 줄로 고정됨
│  써머리 │ 뉴스 │ 시그널 │ 저널          │   ← 좌우 스와이프로도 전환
├─────────────────────────────────────────┤
│                                         │
```

가격 헤더는 어느 탭에 있든 항상 보입니다. 뉴스를 읽다가도 가격이 튀는 걸
알아야 하니까요.

### 1. 써머리 — 종목 메인

이 종목에 대해 알아야 할 걸 위에서부터 훑는 화면입니다.

1. **차트**
   - 기간 칩: `1D · 5D · 1M · 6M · 1Y`
   - 봉 간격 칩: `1m · 5m · 15m · 1H · 1D` (기간에 따라 가능한 것만 활성)
   - 라인 ↔ 캔들 토글
   - 거래량 서브차트
   - 오버레이 토글: EMA 9/21/50, VWAP, 볼린저 밴드
   - 길게 눌러 크로스헤어 — 그 시점의 OHLC와 시각을 헤더에 표시
   - 롤오버가 있는 종목(CL, GC)은 만기 교체 지점에 옅은 세로선

2. **핵심 수치 그리드** (2열)
   ```
   전일종가  62.38     시가      62.55
   일중범위  62.80–63.90        거래량  428K
   52주범위  55.12–87.63        평균거래량 305K
   ATR(14)   0.71     RSI(14)   58.4
   EMA20 대비 +0.8%   EMA50 대비 +2.1%
   ```

3. **지표 요약 바** — 추세 / 모멘텀 / 변동성 / 참여 네 축을 한 줄 게이지로.
   탭하면 시그널 탭으로 점프합니다. "왜 이 숫자냐"는 거기서 설명됩니다.

4. **뉴스 3건** + "더보기" → 뉴스 탭

5. **오늘의 저널 미리보기** — 오늘 쓴 메모 1~2줄과 한 줄 입력창. 비어 있으면
   "오늘 기록 없음"과 입력창만.

### 2. 뉴스

- 무한 스크롤 리스트. 한 줄당: 출처 · 시각("7분 전") · 헤드라인 · 요약 2줄 · 썸네일
- 상단 필터 칩: `전체 · 종목 직접 · 매크로 · 수급`(원유는 `재고·OPEC`, BTC는 `규제·온체인`)
- 상단 고정 이벤트 스트립: 임박한 예정 이벤트가 있으면 `EIA 재고 2시간 12분 뒤`
- 탭하면 원문으로 이동(앱 내 브라우저). 본문을 앱에 복제하지 않습니다 — 저작권 문제이고,
  요약은 원문 RSS가 주는 범위까지만 씁니다.
- 읽은 항목은 흐리게 (기존 career-app의 `feedStates` 패턴과 동일)
- 헤드라인 길게 누르기 → 그 뉴스를 인용한 저널 작성

### 3. 시그널

위에서부터: **지금 뭘 해야 하나 → 왜 그런가 → 지금까지 얼마나 맞았나**

```
┌─────────────────────────────────────────┐
│  ▲  LONG           확신도 72            │
│  ████████████████░░░░░░░                │
│                                         │
│  진입   63.30 – 63.50                   │
│  손절   62.72          (-0.9%, 1.1 ATR) │
│  목표1  64.18          (+1.1%, 1.0R)    │
│  목표2  64.90          (+2.2%, 2.0R)    │
│  손익비 1 : 2.0     유효 23분 남음       │
├─────────────────────────────────────────┤
│  레짐  상승추세 ·  게이트 모두 통과      │
│  변동성 충분(ATR 68%ile) · 세션 활성     │
│  · 예정 이벤트 없음                      │
├─────────────────────────────────────────┤
│  근거                                   │
│  추세      ████████░░  +0.82  EMA 정렬·기울기 양(+)
│  모멘텀    ██████░░░░  +0.55  RSI 50 상향 돌파
│  변동성    ████░░░░░░  +0.40  밴드 확장 시작
│  참여      ███████░░░  +0.71  거래량 z +2.1
│  구조      █████░░░░░  +0.48  VWAP 위 0.3ATR
│  문맥      ░░██░░░░░░  -0.20  달러 강세 소폭
├─────────────────────────────────────────┤
│  최근 시그널                             │
│  09:15 LONG 68   → T1 도달   +1.0R      │
│  08:40 SHORT 61  → 손절      -1.0R      │
│  07:55 LONG 74   → T2 도달   +2.0R      │
├─────────────────────────────────────────┤
│  성적표 (최근 30일)                      │
│  발생 41 · 적중 22 (53.7%) · 기대값 +0.31R

```

게이트에 걸린 상태라면 맨 위 카드가 통째로 대기 화면이 됩니다:

```
│  —  WAIT                                │
│  EIA 재고 발표 8분 전 — 신규 시그널 중단 │
│  발표 후 15분간 재개하지 않습니다        │
```

하단에 이 종목의 시그널 설정: 사용할 봉 간격, 최소 확신도, 알림 on/off.

### 4. 저널

댓글처럼 남기는 그날의 거래 기록. 가장 단순해야 하는 화면입니다.

```
┌─────────────────────────────────────────┐
│  오늘 · 9월 15일                         │
│                                         │
│   09:22  63.40                     ⋯    │
│   62.9 눌림에서 롱. 거래량 실렸고        │
│   VWAP 위 유지.                          │
│   [롱]                                   │
│                                         │
│   10:05  63.88                     ⋯    │
│   T1에서 절반 정리. 나머지는 손절을      │
│   본전으로.                              │
│   [잘함]                                 │
│                                         │
│  어제 · 9월 14일                         │
│   ...                                   │
├─────────────────────────────────────────┤
│  [롱][숏][관망][실수][잘함]   □현재가 첨부│
│  ┌───────────────────────────────┐  ↑  │
│  │ 기록 남기기...                │     │
│  └───────────────────────────────┘     │
└─────────────────────────────────────────┘
```

**쓰기**
- 입력창은 하단 고정, 채팅/댓글과 같은 느낌. 한 줄이면 충분하고 길어지면 늘어납니다.
- 전송은 명시적(↑ 버튼). 단, 쓰다 만 글은 초안으로 보존돼서 앱을 나갔다 와도 남습니다.
- 태그는 한 번 탭으로 붙는 칩 5개: `롱 · 숏 · 관망 · 실수 · 잘함`. 선택 사항입니다.
- `현재가 첨부` 체크 시 그 시각의 가격이 함께 저장됩니다. 나중에 읽을 때 이게 결정적입니다.
- 그 시각 활성 시그널이 있으면 자동으로 연결됩니다("이 기록은 09:15 LONG 시그널 중").

**수정·삭제**
- 각 항목 `⋯` → 수정 / 삭제 / 복사
- 수정하면 본문 옆에 작게 `수정됨`
- 삭제는 확인 한 번 + 5초 실행취소 스낵바 (실수로 지운 기록은 복구 불가이므로)

**읽기**
- 날짜별 그룹, 최신이 위
- 상단에 검색과 태그 필터
- 통합 저널(`/journal`)은 종목 칩이 앞에 붙는 것 말고는 같은 화면

**내보내기** — 설정에서 JSON 또는 마크다운. 기기 안에만 있는 기록이므로 백업이
유일한 안전장치입니다.

## 설정

- 시세 갱신 주기 (5초 / 15초 / 30초 / 수동)
- 상승/하락 색상 (빨강-초록 ↔ 빨강-파랑)
- 표시 시간대 (KST 고정 / 거래소 현지)
- 계좌 1회 리스크 % — 시그널의 포지션 사이즈 힌트 계산에 사용
- 시그널 알림 (웹푸시, iOS 16.4+ 설치 상태에서만)
- 저널 내보내기 / 가져오기
- 데이터 출처와 지연 표시
- 고지 전문

## 화면 전반의 규칙

- **지연을 숨기지 않는다.** 모든 가격 옆에 갱신 시각이 있고, 30초 넘게 오래된 값은
  흐려집니다. 오프라인이면 상단에 띠가 뜹니다.
- **로딩에 스피너를 쓰지 않는다.** 캐시된 값을 먼저 그리고 조용히 갱신합니다.
  첫 실행에만 스켈레톤.
- **색은 정보다.** 방향(상승/하락/롱/숏) 말고는 색을 쓰지 않습니다.
- **엄지 영역.** 자주 쓰는 동작(탭 전환, 저널 입력, 새로고침)은 화면 하단에.
